# DreamFab Releases

Public downloads for **DreamFab** (Windows installer and OTA update packages).

- **Source code is not published here.** It lives in a private repository.
- Install the app from [Releases](https://github.com/cttcruz/DreamFab-Releases/releases) (`Setup.exe`).
- The app checks this repository's Releases feed for updates.

Until the first release is published, there are no downloadable assets yet.
